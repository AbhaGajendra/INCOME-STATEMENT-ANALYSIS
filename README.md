
📊 Income Statement Analysis Dashboard
An interactive and visually appealing financial analysis dashboard built to evaluate company performance across multiple dimensions. This project demonstrates skills in data visualization, financial modeling, and dashboard design, making complex financial data easy to interpret for stakeholders.
________________________________________
🚀 Features
•	Comparative Analysis: Current vs. Previous period values with percentage changes.
•	Key Metrics: Revenue, COGS, Gross Profit, Expenses, EBIT, Finance Costs, Net Income.
•	Visual Insights: Trend charts and donut charts for Net Income Margin.
•	Interactive Filters: Region, Year, and Month selectors for dynamic exploration.
•	Performance Indicators: Highlights growth rates and margin changes.
________________________________________
🛠️ Tech Stack
  DAX: Used for calculated columns and measures. 
•	Power BI  (Dashboard design and interactivity. )
  Power Query: For data transformation and cleaning.
________________________________________
📈 Insights from the Dashboard
•	Revenue grew 101%, showing strong market demand.
•	COGS increased 113%, highlighting margin pressure.
•	Operating expenses doubled, signaling expansion but also efficiency challenges.
•	Net Income Margin stands at 14.43%, a healthy but sensitive figure given rising costs.
This project showcases financial storytelling through data — turning raw numbers into actionable insights.
